AI Physics KZ 8.1.0 — AGENTIC TOOLS + PISA

НЕ ӨЗГЕРДІ
- Мұғалім ЖИ және Оқушы ЖИ енді keyword-router-ға негізгі түрде байланбайды.
- GPT/Responses function calling пайдаланушының кез келген табиғи сөйлемін мағынасы бойынша талдап,
  физикалық сызба, еркін сурет, график, файл/сурет талдау немесе кәдімгі жауап құралын өзі таңдайды.
- Function calling қолжетімсіз ескі SDK/модель болса, екінші semantic JSON planner іске қосылады.
  Тек екеуі де істемесе бұрынғы router соңғы fallback болады.
- Алдыңғы чат контексті құрал таңдау алдында беріледі: «осыны суретпен көрсет», «алдыңғысын графикпен бер» сияқты жалғастырулар түсініледі.
- Оқушы ЖИ де еркін контекстік сурет генерациясын қолдана алады.
- PISA «Автоматты» режимінде ЖИ өзі: кесте / бағандық график / сызықтық график / физикалық схема /
  контекстік сурет / көрнекіліксіз режимдерінің бірін мағынасына қарай таңдайды.
- PISA-да «Сурет» пен «Физикалық схема» енді бөлек режимдер.
- PISA көрнекілігі әшекей емес, кемінде бір сұраққа қажетті дерек/дәлел ретінде жоспарланады.
- Сурет/сызба түсіндірмесі SVG ішіне жазылмайды; чат мәтінінде бөлек беріледі.
