# AI Physics KZ — жаңартылған веб-нұсқа

Физика пәніне арналған мұғалім–оқушы–ЖИ платформасы. Бұл жинақта оқушыны сынып коды арқылы тіркеу, сынып тапсырмаларын дәптермен орындау, PISA, оқушы әрекетін толық бақылау және мұғалімнің әмбебап ЖИ ассистенті бір жүйеге біріктірілген.

v7-де мұғалім және оқушы ассистенттері ортақ multimodal AI Core қолданады: бірнеше сақталатын чат, ұзақ контекст, файл/сурет талдауы, role permission, multi-tool routing және DOCX/PDF/PPTX/PNG/SVG нәтижелері.

## Жылдам іске қосу

Windows: қолданыстағы `.env` файлын компьютеріңіздегі бұрынғы жоба бумасынан осы бумаға көшіріңіз немесе `.env.windows.example` үлгісі негізінде өз серверлік мәндеріңізді орнатыңыз. Кейін `START_WINDOWS.bat` іске қосыңыз. Алғашқы мұғалім аккаунты «Тіркелу → Мұғалім» арқылы жасалады. Мұғалім сынып ашып, кодты оқушыға береді. II турдағы өзгерістерді `ROUND2_FIXES_KZ.md` файлынан қараңыз.

Railway: Variables ішінде `OPENAI_API_KEY`, `OPENAI_MODEL`, `APP_MODE=production`, `ALLOW_USER_API_KEY=false`, `AI_PHYSICS_DB=/app/storage/ai_physics_kz.db`, `AI_PHYSICS_UPLOAD_DIR=/app/storage/uploads`, `AI_PHYSICS_GENERATED_DIR=/app/storage/generated_files` орнатыңыз; `/app/storage` үшін бір persistent volume қосыңыз. Толығырақ `DEPLOY_RAILWAY.md`.

Миграция автоматты орындалады. Қолданба жаңа conversation/file/job кестелерін қосады және бұрынғы деректерді жоймайды. Орналастыру алдында дерекқор backup жасаңыз.

## Негізгі мүмкіндіктер

- «Қозғалыс детективі» бөлімінде 7-сыныпқа арналған бірқалыпты қозғалыстың веб-моделі бар: үш нысан, уақытты басқару, жеке жол–уақыт графиктері, кесте және «болжау → тексеру → қорытынды» тапсырмасы. Оқушы бастапқы мәндерді өзгерте алады; болжанған уақыттың нәтижесі тек тексергеннен кейін ашылады. Мұғалім аккаунты ағымдағы есептердің жауаптарын және ықтимал қателерді көреді. Бұл бөлім браузерде жұмыс істейді, PyQt6 орнатуды қажет етпейді.

- Оқушы және мұғалім аккаунттары.
- Оқушы тіркелгенде сынып нөмірі, әрпі және мұғалім берген сынып коды міндетті түрде тексеріледі.
- Сынып коды қате, бос немесе таңдалған сыныпқа сәйкес болмаса, тіркелу аяқталмайды.
- Мұғалім кабинетінде тіркелген оқушылардың аты-жөні, тіркелген уақыты және соңғы белсенділігі көрінеді.
- «Оқушылар» бөлімінде әр оқушының барлық жауаптары, сынып тапсырмалары, PISA жауаптары және дәптер жұмыстары сақталады.
- Сынып тапсырмасын мұғалім өзі енгізе алады немесе ЖИ-ға құрастырта алады.
- ЖИ құрастырған тапсырма бірден жіберілмейді: мұғалім оны алдын ала көріп, мәтінін, жауабын және шешуін өңдейді.
- Оқушы тапсырманы дәптерге орындайды, суретін жүктейді; жүйе тексеріп, мұғалімге суретпен бірге нәтижесін береді.
- Бір тапсырманы бірнеше рет орындаса, барлық әрекет тарихы сақталады.
- Мұғалімге жеке PISA құрастыру бөлімі қосылған: тақырыпты қолмен енгізу, оқу мақсаты, көрнекілік түрі, алдын ала қарау және сыныпқа жіберу.
- PISA тапсырмаларында кесте, бағандық/сызықтық график немесе сурет/схема қолдануға болады.
- «Мұғалім ЖИ ассистенті» чаты ҚМЖ, БЖБ/ТЖБ, жұмыс парағы, презентация, сурет, тапсырма, түсіндірме және сынып талдауын дайындай алады.
- ЖИ ассистенті Word және PowerPoint файлдарын тікелей дайындайды, ал сурет сұралса көрнекі сурет жасайды.
- PDF/DOCX/TXT/MD/CSV материалдарын жүктеп, ЖИ ассистентіне немесе оқушы көмекшісіне контекст ретінде қолдануға болады.
- Интерфейстің негізгі мәтіндері, мәзірлері, батырмалары, енгізу өрістері және график жазулары Times New Roman қарпімен беріледі.
- Техникалық модель атаулары, қызметтік JSON және ішкі қате кодтары пайдаланушы интерфейсінде көрсетілмейді.

## Іске қосу

### Windows

1. Python 3.11+ орнатыңыз.
2. Жоба бумасында `START_WINDOWS.bat` файлын іске қосыңыз.
3. Серверлік ЖИ кілтін `.env` файлына әкімші енгізеді.
4. Браузерде ашылған сайт арқылы мұғалім аккаунтын құрыңыз.
5. Мұғалім сынып құрып, шыққан кодты оқушыларға береді.

### Қолмен іске қосу

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## Серверлік баптау

ЖИ қызметінің кілті браузерге немесе оқушы интерфейсіне шығарылмайды. Оны тек сервердегі `.env`/hosting secrets арқылы сақтау керек. Жоба қолданыстағы конфигурациямен `OPENAI_API_KEY` және қажет болса `OPENAI_MODEL` орта айнымалыларын оқиды.

Railway үшін `RAILWAY_DEPLOY_KZ.md` нұсқаулығын пайдаланыңыз.

## Деректер

Әдепкі режимде SQLite қолданылады. Жүйеде келесі тарих сақталады:

- диагностика және адаптивті оқу әрекеттері;
- әр сұраққа берілген жауап;
- сынып тапсырмаларының барлық әрекеттері;
- дәптер суреттерінің барлық жіберілімдері;
- мұғалім берген PISA жауаптары;
- мұғалім ЖИ ассистентінің чат тарихы.
- әр онлайн тесттің жеке нәтижесі, сұраққа жұмсалған уақыт және сұраққа бөлек камера бейнежазбасы.

## Онлайн тест және камера

«Сынып тапсырмалары» бөлімінде мұғалім «Онлайн тест» түрін таңдайды, 1–30 сұрақ дайындайды, барлық сұрақтың дұрыс жауабын енгізеді және сыныпқа жібереді. Оқушы тестті бастаған соң әр сұрақ үшін камераға рұқсат беріп, бейнені жазады, жауабын сақтайды. Бір сұрақтың жазбасы 60 секундқа дейін және 4 МБ-тан аспайды. Сұраққа жұмсалған жалпы уақыт пен нәтиже бөлек сақталады. Оқушы қорытынды есебін көреді, ал мұғалім әр сұрақтың бейнесін өз панелінде аша алады.

Камера браузерде тек HTTPS мекенжайында немесе жергілікті `localhost` арқылы жұмыс істейді. Камераға браузер рұқсатын беру қажет. Бейнежазбалар сервердегі SQLite дерекқорында сақталады: тұрақты сақталуы үшін `data` каталогын резервтік көшіруге немесе серверде тұрақты томға бекітуге болады.
